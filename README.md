# LastFM Event Notifier

## Overview
The LastFM Event Notifier is a project designed to help users keep track of the latest events from their favorite artists on LastFM. By using this tool, users can receive notifications when their artists have new concert dates.

## Setup Instructions
Follow the steps below to set up the LastFM Event Notifier:

### Prerequisites
- Ensure you have [Node.js](https://nodejs.org/) installed on your machine.
- You will need an API key from LastFM. You can get it by registering your application at [LastFM API](https://www.last.fm/api/account/create).
